3. Ask for your first test

In Cursor’s Agent chat, say:

“Use Feena to show me the available tests. Explain what they do and ask before running one.”

Feena runs only tests prepared for this workspace—not any website you paste in. Tests may create or change data, so use a disposable test app.

A failed test means something needs investigation. A passing test means this specific journey passed—not that every possible user experience was tested.

Need help? An invalid key? Ask your workspace administrator for a new one. Cursor didn’t open? Install or update Cursor desktop and try again. Your app isn’t listed? It still needs to be connected by your administrator.
