3. Confirm the connection in Cursor

If Cursor lists your workspace’s tests, the connection is working. Opening the installation link alone does not confirm installation.

Feena runs only tests prepared for this workspace. Tests may change data, so use a disposable test app. A passing result covers that specific journey, not every possible user experience.

Need help?

Invalid key? Ask your workspace administrator for a new one. Cursor didn’t open? Install or update Cursor desktop, then try again. App not listed? Ask your administrator to connect it and prepare its journeys.
